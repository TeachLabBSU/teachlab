# TeachLab — Frontend

Frontend приложение веб-платформы TeachLab (Single Page Application на базе React 18, TypeScript и Vite).

Предоставляет интерфейс для преподавателей и учеников: аутентификацию, управление учебными классами по инвайт-кодам и личный кабинет.

![Интерфейс TeachLab](src/assets/hero.png)

---

## 1. Стек технологий

- **Среда выполнения и сборщик:** Node.js 20+, Vite
- **Язык разработки:** TypeScript
- **Фреймворк:** React 18 (хуки useState, useEffect)
- **Стилизация:** Адаптивный CSS3 (темная тема, карточки классов)
- **Сетевое взаимодействие:** Fetch API с заголовком `Authorization: Bearer <JWT>`

---

## 2. Основной функционал

### Аутентификация и профиль
- Формы переключения между входом и регистрацией с валидацией полей.
- Выбор роли при регистрации: Преподаватель (`tutor`) или Ученик (`student`).
- Автоматическое восстановление сессии из `localStorage` через запрос к `/api/v1/auth/me`.
- Выход из аккаунта (Logout).

### Личный кабинет преподавателя (Tutor)
- Создание учебного класса с сохранением в базу данных.
- Список созданных классов со счетчиком записавшихся учеников.
- Уникальный 6-значный инвайт-код с кнопкой копирования в буфер обмена.
- Перегенерация инвайт-кода при необходимости.
- Удаление класса с подтверждением.

### Личный кабинет ученика (Student)
- Форма ввода инвайт-кода для подключения к классу.
- Список классов, в которых ученик состоит.
- Выход из класса.

## 4. Запуск и сборка

### Запуск в Docker Compose (рекомендуется)
Из корня проекта `teachlab`:
```bash
docker compose up -d --build
```
Интерфейс будет доступен по адресу: http://localhost:5173

### Локальный запуск через Node.js
Из директории `frontend/`:
```bash
# Установка зависимостей:
npm install

# Запуск сервера разработки:
npm run dev

# Проверка типов и сборка бандла:
npm run build
```
