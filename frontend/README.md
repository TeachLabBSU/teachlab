# TeachLab — Frontend Client

Клиентская часть веб-платформы **TeachLab** (Single Page Application).

Приложение предоставляет интерактивный интерфейс для преподавателей и учеников: управление виртуальными классами, решение контрольных работ в браузере в режиме реального времени с ограничением по таймеру и отрисовку сложных математических формул.

## 1. Стек используемых технологий

* **Среда выполнения и сборщик:** Node.js 20+, Vite (быстрая сборка с поддержкой Hot Module Replacement — HMR)
* **Язык разработки:** TypeScript (статическая типизация данных)
* **Фреймворк:** React 18 (компонентный подход, хуки состояния)
* **Стилизация интерфейса:** Tailwind CSS (утилитарные стили, темная тема оформления)
* **Отображение математики:** KaTeX (быстрый рендеринг формул из синтаксиса LaTeX)
* **Маршрутизация:** React Router v6
* **Взаимодействие с API:** Native Fetch API с поддержкой авторизации через заголовок `Authorization: Bearer <JWT>`

## 2. Прототипы страниц (UI/UX Дизайн)

Проектирование интерфейса ведется в графическом редакторе **Figma** по концепции *Mobile-First* с последующей адаптацией под экраны ПК.

> [Figma](https://figma.com/design/V3jkb37W6PehBEcs4ovea4/First-try?node-id=19-2&t=gDc8L9BugWXRdsfI-0)

## 3. Взаимодействие с API сервера

Фронтенд не хранит состояние персистентно — все данные (пользователи, классы, банк задач, результаты тестов) получаются и отправляются на сервер посредством асинхронных HTTP-запросов (REST API) в формате JSON.

## 4. Локальный запуск и разработка

### Вариант 1: Через Docker Compose (Вместе со всей системой)

Из корня проекта `teachlab`:

```bash
docker compose up -d --build
```

Интерфейс будет доступен по адресу:  **`http://localhost:5173`**

### Вариант 2: Локальный запуск через Node.js

Из папки `frontend/`:

```bash
npm install
npm run dev
```

Интерфейс будет доступен по адресу:  **`http://localhost:5173`**
