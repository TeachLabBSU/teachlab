# TeachLab — Backend Service

**TeachLab** — серверная часть веб-платформы для комплексной автоматизации работы репетиторов, преподавателей и образовательных центров. Сервис предоставляет REST API для управления учебными классами, ведения личного банка задач с поддержкой формул LaTeX, генерации контрольных работ и автоматической проверки решений учеников.

## 1. Стек используемых технологий

* **Язык разработки:** Python 3.11+
* **Фреймворк:** FastAPI (асинхронный веб-фреймворк для создания REST API)
* **Сервер приложений:** Uvicorn (высокопроизводительный ASGI-сервер)
* **СУБД:** PostgreSQL 15 (развертывание в изолированном контейнере Docker)
* **ORM и миграции:** SQLAlchemy 2.0 (работа через современный драйвер `psycopg v3`) + Alembic
* **Безопасность и криптография:**  
  * Хэширование паролей с криптографической солью через алгоритм `bcrypt`;
  * Аутентификация и авторизация на базе JWT-токенов (`PyJWT`, стандарт OAuth2 Bearer).

## 2. Роли пользователей и варианты использования (Use Case)

В системе реализовано ролевое разграничение доступа (Role-Based Access Control — RBAC):

1. **Преподаватель (Tutor):**
   * Создание виртуальных учебных групп и управление инвайт-кодами для учеников;
   * Наполнение личного банка задач (условия, параметры сложности, разметка формул LaTeX);
   * Формирование контрольных работ (ручная выборка или автогенерация по темам) и установка таймеров;
   * Просмотр журнала сданных работ, ручная корректировка баллов и комментирование ошибок.

2. **Ученик (Student):**
   * Вступление в класс преподавателя по инвайт-коду;
   * Прохождение назначенных тестирований в браузере в режиме реального времени с обратным отсчетом времени;
   * Просмотр проверенных результатов с детализацией по каждой задаче.

## 3. Схема базы данных (ER-диаграмма)

База данных спроектирована в третьей нормальной форме (3NF) с использованием формата `JSONB` для гибкого хранения условий задач с математическими формулами и параметров валидации ответов.

### Ключевые сущности

* **`users`** — аккаунты пользователей, хэши паролей с солью и системные роли (`tutor`, `student`).
* **`study_group`** — учебные группы преподавателя с уникальными инвайт-кодами.
* **`group_member`** — связь учеников с учебными группами.
* **`task`** — банк задач с темами, баллами, содержимым условий (`content`) и схемами проверки (`validation_schema`).
* **`assessment`** — проверочные работы и тесты с дедлайнами и таймерами.
* **`test_task`** — привязка конкретных задач к контрольной работе с фиксацией их порядкового номера.
* **`submission` & `student_answer`** — протоколы сдачи работ учениками с сохраненными ответами, автопроверкой и баллами.
